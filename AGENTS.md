# Project Rules

## Stack

- Vite
- Vanilla TypeScript
- No React
- GitHub Pages deployment

## Architecture

src/
├─ terminal/
├─ commands/
├─ services/
├─ styles/

## Design

Terminal-style UI

- Black background
- Green text
- Monospace font
- Keyboard driven

## Code Style

- Strict TypeScript
- Modular architecture
- No inline styles
- No jQuery

## Commands

help
clear
history
rank
guess

## Storage

Use localStorage.

## Deployment

Must work on GitHub Pages.

Do not introduce server-side code.

Never use:
- Express
- Node backend
- Database
- WebSocket server

This project must run as a static website only.
